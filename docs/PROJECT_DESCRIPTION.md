# Deskripsi Lengkap CloudVault

CloudVault adalah platform penyimpanan cloud yang di-hosting sendiri, dibangun untuk menjawab kebutuhan privasi data dan kendali penuh atas infrastruktur, dengan Nextcloud sebagai aplikasi cloud storage utama dan Nginx sebagai gateway yang menangani seluruh traffic. Aplikasi ini di-install langsung di atas Debian 13 (Trixie) melalui APT tanpa Docker atau container, sehingga bersifat ringan, transparan, dan mudah didebug dengan alat standar Linux seperti systemctl dan journalctl, tanpa biaya lisensi atau langganan bulanan. Seluruh data tersimpan di server milik sendiri dan tidak pernah keluar dari kendali pemiliknya.

Fitur utamanya mencakup dashboard penyimpanan untuk upload, download, sharing, dan sinkronisasi file antar perangkat via WebDAV; keamanan berlapis mulai dari TLS 1.3 saja dengan HSTS preload, rate limiting, Fail2ban yang otomatis mem-blacklist IP percobaan brute-force, sampai ClamAV yang memindai setiap file upload secara real-time sebelum disimpan; backup terenkripsi AES-256 dengan verifikasi SHA-256 dan rotasi otomatis 7 harian, 4 mingguan, dan 12 bulanan; maintenance otomatis lewat systemd timer termasuk perbaikan indeks database dan pre-generate preview; dan monitoring Prometheus + Grafana dengan Alertmanager yang memberi peringatan saat penyimpanan melewati 85%, ada service yang mati, atau sertifikat SSL hampir kadaluarsa.

Project ini juga dilengkapi CloudVault Watchtower, sebuah bot Telegram yang menghubungkan chat dengan infrastruktur server: pengguna bisa cek status, health, metrik, dan storage cukup lewat perintah `/status`, `/health`, `/storage`, dan lainnya. Akun di-link menggunakan token sekali pakai yang valid 10 menit, sehingga password tidak pernah dikirim lewat Telegram, dan notifikasi event seperti backup selesai atau gagal, alert keamanan, serta peringatan penyimpanan otomatis terkirim ke semua pengguna yang terhubung.

Aplikasi ini juga dirancang sebagai single source of truth: seluruh konfigurasi produksi (Nginx, PHP-FPM, PostgreSQL, Redis, Fail2ban, UFW, Prometheus) disimpan sebagai code dalam repository yang idempotent dan version-controlled. Setup server baru atau pemulihan bencana cukup dilakukan dengan menyalin repository lalu menjalankan satu perintah `sudo bash scripts/install.sh all` — installer mengerjakan semuanya berurutan dari persiapan sistem, pemasangan paket, konfigurasi database, sampai hardening keamanan dan backup, tanpa konfigurasi manual yang berbelit.

Hasil kerjanya sudah diukur: response time HTTP rata-rata sekitar 0,1 detik per request, TLS handshake sekitar 0,03 detik, dan download file 25 MB via WebDAV mencapai kecepatan terbaik ±33–38 MB/s. Semua proses teraudit dari log Nginx, log aplikasi, log ClamAV, sampai log verifikasi backup, sehingga project ini sekaligus menjadi bukti kompetensi di bidang administrasi server Linux, arsitektur web server, security hardening, performance tuning, dan infrastructure as code.
